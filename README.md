# Cardiovascular Disease Detection (CVDD)

## Project Overview
The Cardiovascular Disease Detection (CVDD) project is an end-to-end application developed to assist in predicting cardiovascular diseases based on user inputs. The project leverages machine learning algorithms and a user-friendly interface built with Streamlit to provide real-time predictions and insights.

### Key Features
- **Assisting:** providing the basic information about the how heart diseases are occured and measures to tackle those issues.
- **User Input:** Users can input various health parameters to get predictions about cardiovascular disease risk.
- **Model Prediction:** Utilizes an XGBoost model trained on cardiovascular health data for accurate predictions.
- **Interactive UI:** Built with Streamlit for an intuitive user experience.
- **Health Insights:** Provides information about heart diseases, types, and tips for maintaining a healthy heart.


## Technologies Used
- Python
- Streamlit
- Scikit-Learn
- Pandas
- NumPy
- XGBoost
- Matplotlib (for any visualizations)
- seaborn
